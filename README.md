# cotiza

Necesitamos agregar unas variables a considerar desde el origen:

BUSQUEDA DE PATRONES en un BUNDLE DE OFERTAS que INDEXAREMOS para encontrar: secciones, textos, parámetros en común, template típico, cotizaciones, formatos, etc.

Actualizaciones web de cotizaciones de materiales, monedas, estimaciones de inflación, monedas, contextos adversos, etc.

Secciones tipicas, antecedentes que respaldan los servicios de igual o superior magnitud

CUMPLIMIENTO LEGAL, adecuarse a la LEY DE COMPRAS o LEY CIVIL COMERCIAL que le quepa al servicio cotizado, consultar las variables, de marcos legales, financieros,, cronograma de pagos, penalizaciones, tarifas de salida, garantías, etc.

Seguimiento: cronograma, prórrogas, consultas, contexto, proceso de consultas, aperturas, garantías, reclamos, impugnaciones, contrato

Competitividad: analisis retroactivo de procesos similares, ofertas de productos y servicios equivalentes, competencia en la misma zona de incumbencia, et.c
